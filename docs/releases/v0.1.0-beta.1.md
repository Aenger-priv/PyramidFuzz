# Pyramid Fuzz v0.1.0-beta.1

First downloadable macOS beta: a schematic-guided fuzz with passive Tone/High,
loaded Sustain, distinct Off/Silicon/Germanium diode modes and 2x/4x/8x
oversampling. Includes the black/gold app icon, clearer control values/help,
timed dBFS meters and fixed six-sample host latency.

## Downloads

- **Pyramid-Fuzz-v0.1.0-beta.1-macOS-Universal-AU.zip** — Audio Unit for Logic,
  GarageBand and other AU hosts.
- **Pyramid-Fuzz-v0.1.0-beta.1-macOS-Universal-Standalone.zip** — app for playing
  without a DAW.
- **SHA256SUMS.txt** — checksums for both ZIPs.
- **build-info.json** — build identity, executable hashes and validation scope.

Choose an uploaded binary ZIP, not GitHub's automatic Source code archive.
Both ZIPs contain Apple Silicon and Intel code and include installation notes.

## Installation

**AU:** Quit your host, unzip the AU download, and copy the entire
`Pyramid Fuzz.component` into `~/Library/Audio/Plug-Ins/Components/`. Restart the
host and select **Audio Units → Anders → Pyramid Fuzz** in an audio effect slot.

**Standalone:** Unzip the app download, copy `Pyramid Fuzz.app` into Applications,
open it, allow input access and select your guitar interface in audio settings.

These are **ad-hoc signed, unnotarized beta builds**. macOS may block downloaded
copies. See [installation and macOS approval guidance](https://github.com/Aenger-priv/PyramidFuzz/blob/v0.1.0-beta.1/docs/installation.md).

## Validation and limits

- Six automated test groups and AU validation pass. GarageBand editor, playback,
  native bypass, WAV export and project setting recall were tested.
- Tested on Apple Silicon, macOS 27.2.1, GarageBand 10.4.14. Deployment target
  is macOS 12.0. Intel and older-macOS runtime behavior remain unverified.
- Logic is an intended AU host; this plugin has not yet been tested inside Logic.
- Default **4x** is recommended for playing. Extreme 96 kHz/8x/stereo/32-frame
  processing remains CPU-heavy. The 4x extreme-bright/high-drive alias target
  remains unmet. See the [quality report](https://github.com/Aenger-priv/PyramidFuzz/blob/v0.1.0-beta.1/docs/processing-quality-review.md).
- Existing sessions retain parameter values and use the revised sound.
- Manual host automation, full keyboard/fine-drag interaction and final guitar
  acceptance on this delivered build remain open checks.

The packaged executables are the validated 0.1.0 builds from `c14de77`. Plugin
source, assets, JUCE pin and build configuration are unchanged between that
validated revision and this release; subsequent changes document and package it.
Bundle versions remain 0.1.0; this beta is identified by the release tag, ZIP
names and checksums.

Please report issues with Mac/OS, host/interface, buffer size, control settings
and reproduction steps: https://github.com/Aenger-priv/PyramidFuzz/issues
